1. 프로그램 소개
================================================================================

Chord Sync는 일렉트릭 기타 중급자를 위한 즉흥연주(Improvisation) 학습 도구입니다.

【핵심 개념】
  일렉 기타를 배우는 많은 사람들이 스케일은 외워도 "실제로 무슨 음을 언제 쓰는가?"를
  몰라서 즉흥연주가 어렵습니다. 이 프로그램은 YouTube나 로컬 영상과 Chordify에서
  추출한 MIDI 파일을 동기화하여, 음악이 재생되는 동안 기타 지판에 실시간으로
  "지금 이 순간 사용할 수 있는 음"을 시각적으로 보여줍니다.

【이런 분께 추천】
  · 펜타토닉은 외웠지만 코드 진행에 맞춰 뭘 쳐야 할지 막막한 분
  · 논-다이아토닉(비조성) 코드가 나올 때 어떤 음을 피해야 하는지 모르는 분
  · 좋아하는 곡을 들으면서 즉흥연주를 연습하고 싶은 분
  · 기타 이론을 눈으로 보며 이해하고 싶은 분

【필요한 것】
  · 웹 브라우저 (Chrome / Edge 권장)
  · Chordify (chordify.net) 에서 추출한 .mid 파일
  · YouTube 링크 또는 로컬 영상 파일 (mp4, webm 등)
  · 인터넷 연결 (YouTube 사용 시, Tailwind CSS 로딩 시)

2. 빠른 시작 (Quick Start)
================================================================================

Step 1. index.html 파일을 크롬/엣지 브라우저로 열기
        (더블클릭 또는 브라우저에 파일을 드래그)

Step 2. Chordify에서 MIDI 파일 받기
        ① chordify.net에서 원하는 곡 검색
        ② 곡 페이지에서 "EXPORT → MIDI" 버튼 클릭
        ③ 다운로드된 .mid 파일을 프로그램 상단 MIDI 업로드 영역에 드래그하거나 클릭

Step 3. 영상 연결
        [YouTube 탭] YouTube URL 또는 영상 ID를 입력 후 [불러오기]
        [로컬 파일 탭] mp4/webm 파일을 드래그하거나 클릭하여 업로드

Step 4. 영상을 재생하면 자동으로 지판이 업데이트됩니다!
        · 빨간 점 = 현재 코드의 근음 (Root)
        · 초록 점 = 코드 구성음 (Chord Tone)
        · 파란 점 = 조성 안 음 (Diatonic)
        · 황금 점 = 조성 밖 음 (Non-Diatonic, 주의 필요)

Step 5. (선택) 동기화가 안 맞으면 Sync Offset 슬라이더로 보정

4. 주요 기능 상세 설명 & 기타 이론
================================================================================

────────────────────────────────────────
4-1. Master Key (조성 설정)
────────────────────────────────────────

  화면 상단 [Master Key] 드롭다운에서 조성(Key)의 루트와 메이저/마이너를 선택합니다.

  【기타 이론】 조성(Key/Tonality)이란?
    음악에서 중심이 되는 음(으뜸음, Tonic)과 그 주변 음들의 체계입니다.
    예: C Major = C D E F G A B (7개의 다이아토닉 음)
        A Minor = A B C D E F G

    MIDI 파일을 불러오면 Krumhansl-Schmuckler 알고리즘으로 조성을 자동 감지하여
    드롭다운이 자동 설정됩니다. 만약 감지가 틀렸다고 느끼면 수동으로 변경하세요.

  【활용 팁】
    조성을 변경하면 지판의 색이 즉시 바뀝니다. 같은 코드라도 다른 조성에서는
    "다이아토닉"이 될 수도, "논-다이아토닉"이 될 수도 있습니다.
    예: G7 코드는 C Major에서 V7 (완벽한 다이아토닉), F Major에서는 II7 (논-다이아토닉)

────────────────────────────────────────
4-2. 지판 색상 범례 (Legend)
────────────────────────────────────────

  ● 빨간색 (Root)
    현재 코드의 근음(으뜸음). 가장 중요한 음입니다.
    즉흥연주 시 프레이즈를 근음에서 시작하거나 끝내면 안정감이 생깁니다.

  ● 초록색 (Chord Tone, 코드톤)
    현재 코드의 구성음 (근음 포함, 다이아토닉 범위 내).
    즉흥연주의 "타깃 노트"입니다. 이 음들에 착지하면 화성적으로 안전합니다.

  ● 황금/앰버색 (Non-Diatonic 코드톤)
    현재 코드의 구성음이지만 조성 밖 음. 예: C Major에서 Eb (♭3).
    이 음은 독특한 색깔을 만들지만, 주변 다이아토닉 음과 충돌할 수 있습니다.
    → 이 음을 "리드" 삼아 연주하면 그루비한 느낌이 납니다.

  ● 파란색 (Diatonic, 다이아토닉)
    조성 안에 있는 음이지만 현재 코드의 구성음은 아닌 음.
    지나가는 음(Passing Tone)이나 색깔음(Color Tone)으로 사용합니다.

  ● 인디고 점선 (Approach Note) ★ NEW
    크로매틱 어프로치 노트 — 코드톤 바로 반음 아래 음.
    [Approach] 토글 활성 시 표시. 이론 설명은 4-9 참조.

  ● 앰버 점선 (Ghost, Pre-NonD)
    다음 코드에 추가될 논-다이아토닉 음의 미리보기.
    [Pre NonD] 토글 활성 시 표시.

────────────────────────────────────────
4-3. Sync Offset (동기화 보정)
────────────────────────────────────────

  MIDI 파일과 영상의 시작 시점이 맞지 않을 때 사용합니다.
  슬라이더를 좌우로 조정하면 MIDI 이벤트를 앞당기거나 늦춥니다.

  예: 코드가 실제보다 0.5초 늦게 바뀐다 → 슬라이더를 +500ms 방향으로

────────────────────────────────────────
4-4. 도수 / 음계 토글 (Label)
────────────────────────────────────────

  지판 점 안의 숫자/문자 표시 방식을 전환합니다.

  [도수 모드] (기본): 현재 코드 루트 기준 음정 관계 표시
    R = 근음, ♭3 = 단3도, 5 = 완전5도, ♭7 = 단7도...

  [음계 모드]: 실제 음 이름 표시
    C, D, Eb, G...

  【활용 팁】
    처음에는 "음계 모드"로 음의 이름을 파악하고,
    익숙해지면 "도수 모드"로 음정 관계를 파악하는 훈련을 권장합니다.
    도수로 생각하면 어느 조성에서도 같은 패턴을 적용할 수 있습니다.

────────────────────────────────────────
4-5. Pentatonic 모드
────────────────────────────────────────

  지판에 Master Key의 펜타토닉 스케일 음만 표시합니다.
  ※ 코드가 바뀌어도 루트는 Master Key 루트로 고정.

  색상 분류 (Pentatonic 모드 전용):
  · 청록색 (Penta): 펜타토닉 음 (중립)
  · 황금색 (Penta-Match): 논-다이아토닉 코드에서 코드톤과 일치 → 적극 사용!
  · 어두운 회색 (Penta-Avoid): 코드톤과 반음 충돌 → 조심해서 사용

  【기타 이론】 펜타토닉 스케일이란?
    5음 스케일. 가장 "안전하고 익히기 쉬운" 즉흥연주 도구.

    Major Pentatonic (메이저): 1 - 2 - 3 - 5 - 6
    → C Major Penta: C D E G A
    → 밝고 경쾌한 느낌. 팝, 컨트리, 록.

    Minor Pentatonic (마이너): 1 - ♭3 - 4 - 5 - ♭7
    → A Minor Penta: A C D E G
    → 어둡고 강렬한 느낌. 블루스, 록, 메탈.

  【활용 팁】
    펜타토닉 모드에서 "Penta-Match (황금색)" 음이 보이면 그 음에 집중하세요.
    논-다이아토닉 코드가 나올 때 그 음이 핵심 색깔을 만들어냅니다.

────────────────────────────────────────
4-6. Chord Only 모드
────────────────────────────────────────

  코드톤(근음 + 코드 구성음 + 논-다이아토닉 코드톤)만 지판에 표시합니다.
  다이아토닉 스케일 음들은 숨겨져 코드 아르페지오에 집중할 수 있습니다.

  【기타 이론】 코드톤 중심 즉흥연주 (Chord Tone Soloing)
    재즈와 고급 즉흥연주의 핵심 개념. 각 코드의 구성음(1, 3, 5, 7)을 중심으로
    멜로디를 구성하면 어떤 복잡한 코드 진행 위에서도 자연스러운 라인이 나옵니다.
    Charlie Parker, Pat Metheny 같은 재즈 기타리스트들의 기본 기법.

────────────────────────────────────────
4-7. Pre NonD 모드 (Pre-Non-Diatonic 미리보기)
────────────────────────────────────────

  다음 코드가 논-다이아토닉(비조성)일 때, 현재 지판에 추가될 음을
  반투명 앰버 점선 점으로 미리 표시합니다.

  【기타 이론】 왜 미리 보는가?
    논-다이아토닉 코드로 진행하기 직전에 그 코드의 특이한 음을 살짝 예고하면
    (= Anticipation, 예측 어프로치) 진행이 매우 매끄럽게 느껴집니다.
    예: C Major에서 Eb Major로 가기 전, 현재 구간의 마지막에 Eb 음을
        살짝 넣어주면 자연스러운 전조(Modulation) 느낌이 납니다.

────────────────────────────────────────
4-8. Gray 모드
────────────────────────────────────────

  논-다이아토닉 음과 근음 외의 모든 음을 회색으로 표시합니다.
  "지금 어떤 음이 특별한가?"에만 집중할 수 있습니다.

  【활용 팁】
    코드 진행이 복잡할 때 Gray 모드를 켜면 황금색(논-다이아토닉)과
    빨간색(근음)만 눈에 띄어, 핵심 색깔음 파악이 쉬워집니다.

────────────────────────────────────────
4-9. Approach Note 모드 ★ NEW
────────────────────────────────────────

  지판에 인디고 점선 점(→)으로 크로매틱 어프로치 노트를 표시합니다.
  어프로치 노트 = 코드톤 바로 반음(½음) 아래 음.

  예: C Major 코드 (코드톤: C, E, G)
    → B (C의 반음 아래), D# (E의 반음 아래), F# (G의 반음 아래)
    이 B, D#, F# 위치에 인디고 점선 점이 표시됩니다.

  【기타 이론】 크로매틱 어프로치 노트 (Chromatic Approach Note)
    재즈와 비밥(Bebop)의 핵심 기법. 코드톤으로 "미끄러지듯" 접근하는 방법.

    원리:
      코드가 바뀌는 순간, 코드톤 바로 반음 아래 음에서 코드톤으로 이동하면
      강한 해결감(Resolution)이 생깁니다. 마치 코드톤으로 "착지"하는 느낌.

    기보 예: Am7 코드 위에서 근음(A=5프렛) 전에 G#(4프렛)을 경유
      │---4h5---│ (4번 해머온 5번)

    연주 방법:
      1. 코드톤(예: A, C, E, G)을 먼저 파악 (지판의 빨간/초록 점)
      2. Approach 모드를 켜서 반음 아래 위치(→ 점) 확인
      3. → 점에서 코드톤 점으로 해머온 또는 슬라이드로 연결

    이 기법을 쓰면:
      · 단순한 펜타토닉 라인이 재즈처럼 세련된 느낌으로 변합니다
      · 코드 체인지가 더 자연스럽고 드라마틱하게 들립니다
      · "음표와 음표 사이의 긴장-해결"을 몸으로 체험할 수 있습니다

  【활용 팁】
    Approach 모드는 일반 모드나 Chord Only 모드와 함께 쓰면 효과적입니다.
    처음에는 2현(B스트링)이나 1현(high e스트링)에서 어프로치 연습을 시작하세요.

────────────────────────────────────────
4-10. Next Board (다음 코드 지판)
────────────────────────────────────────

  현재 지판 아래에 다음 코드의 지판을 60% 투명도로 추가 표시합니다.
  코드 체인지를 미리 시각적으로 준비할 수 있습니다.

  【활용 팁】
    코드가 바뀌기 직전에 "다음 지판의 빨간 점(근음)"으로 시선을 이동하는
    훈련을 하세요. 실제 즉흥연주에서도 "다음 코드를 한 박자 일찍 생각하는" 것이
    프로 연주자들의 핵심 습관입니다.

────────────────────────────────────────
4-11. Improv (즉흥연주 도구 패널)
────────────────────────────────────────

[Improv] 버튼으로 패널을 열면 4가지 탭이 나타납니다.

  ┌────────────┬──────────┬───────────────┬───────────────┐
  │  타임라인  │  운지표  │  아르페지오   │  릭 라이브러리 │
  └────────────┴──────────┴───────────────┴───────────────┘

  ─── 4-11-1. 타임라인 ───────────────────────────────────

  현재 코드와 다음 4개 코드를 카드 형태로 표시합니다.
  각 카드에:
    · 코드명 (예: Am7)
    · 로마 숫자 (예: vi m7) ★ NEW
    · 운지 다이어그램 (SVG 코드 다이어그램)
    · 논-다이아토닉 여부 (황금/앰버 강조)

  카드 크기는 현재→미래 순으로 점점 작아지고 투명해집니다.

  ─── 4-11-2. 운지표 (Chord Voicing) ────────────────────

  현재 코드에 사용 가능한 운지 폼(Form)들을 SVG 다이어그램으로 표시합니다.
  카드를 클릭하면 해당 운지가 선택되어 타임라인에 반영됩니다.

  【기타 이론】 운지 선택의 중요성
    같은 Am7이라도 5현 2프렛 폼(개방형)과 6현 5프렛 바레(E형) 폼은
    음색이 다르고, 특히 다음 코드로 이동하는 손의 움직임도 달라집니다.
    스마트 운지 선택 기능:
      1순위: 사용자가 클릭하여 선택한 운지
      2순위: 이전 코드의 위치에서 가장 가까운 운지 (최소 이동)
      이 선호도는 곡 파일별로 자동 저장됩니다.

  ─── 4-11-3. 아르페지오 TAB ────────────────────────────

  현재 코드의 코드톤을 아르페지오 패턴으로 6줄 TAB 표기합니다.
  [이전 패턴] / [다음 패턴] 버튼으로 5가지 패턴을 순환합니다:
    1. 상행 아르페지오 (저음→고음)
    2. 하행 아르페지오 (고음→저음)
    3. 상행+하행 (저음→고음→저음)
    4. 1-3-5-3 패턴 (재즈/클래식 스타일)
    5. 스위프 패턴 (스위프 피킹 연습)

  색상:
    빨간색 숫자 = 근음(Root)
    황금색 숫자 = 논-다이아토닉 코드톤 (특별 주목)

  ─── 4-11-4. 릭 라이브러리 ★ NEW ──────────────────────

  현재 코드 타입에 맞는 실전 기타 릭(Lick)을 TAB으로 제공합니다.
  코드 루트에 맞게 프렛 번호가 자동으로 조옮김되어 표시됩니다.

  카드 구성:
    · 릭 이름 & 스타일 (Blues, Jazz, Rock 등)
    · 난이도 (★☆☆ ~ ★★★)
    · 이론 설명 (이 릭이 왜 효과적인지)
    · 6줄 TAB 표기

  카드 색상 코드:
    황금(Minor): 마이너/m7 코드용 릭
    초록(Major): 메이저/maj7 코드용 릭
    빨강(Dom7):  도미넌트 7 코드용 릭
    보라(Dim):   디미니시드 코드용 릭
    앰버(Non-D): 논-다이아토닉 코드용 릭

  TAB 기호:
    숫자     = 프렛 번호 (0 = 개방현)
    b        = 벤딩 (Bend) — 황금색으로 표시
    h        = 해머온 (Hammer-on) — 파란색으로 표시
    p        = 풀오프 (Pull-off)
    ---      = 그 줄에서는 이 박자에 음 없음

  기준 포지션 안내가 카드 하단에 표시됩니다.
  예: "기준 포지션: G — 로우 E 3프렛 근처"

────────────────────────────────────────
4-12. 로마 숫자 & 스케일 추천 ★ NEW
────────────────────────────────────────

  영상이 재생되면 Now Playing 영역에 두 가지 정보가 추가됩니다.

  [로마 숫자 배지]
    코드명 아래에 코드의 기능을 로마 숫자로 표시합니다.
    예: Am7 → "vi m7"   G7 → "V 7"   Eb → "♭III"

    색상:
      인디고색 = 조성 안 코드 (Diatonic)
      황금색   = 조성 밖 코드 (Non-Diatonic, 차용화음 등)

  [스케일 추천 (💡 추천:)]
    현재 코드에서 사용하기 좋은 스케일/어프로치를 추천합니다.
    예:
      I  코드 → 메이저 스케일, 메이저 펜타
      ii 코드 → 도리안, 마이너 펜타
      V7 코드 → 믹솔리디안, 블루스, 얼터드(재즈)
      vi 코드 → 에올리안, 마이너 펜타
      논-다이아토닉 코드 → 크로매틱 어프로치, 코드 루트 기준 마이너 펜타

  【기타 이론】 로마 숫자 기능화 (Roman Numeral Analysis)
    각 코드를 조성 안에서의 역할(기능)로 표현하는 방법.

    C Major의 경우:
      I    = C     (으뜸화음, Tonic — 안정감, 쉬는 느낌)
      ii   = Dm    (위아래음, Supertonic — 약한 긴장)
      iii  = Em    (중앙음, Mediant)
      IV   = F     (버금딸림화음, Subdominant — 따뜻한 움직임)
      V    = G     (딸림화음, Dominant — 강한 긴장 → I로 해결)
      vi   = Am    (관계단조, Relative Minor — 우울하고 서정적)
      vii° = Bdim  (이끔화음, Leading Tone — V와 유사한 긴장)

    이 관계를 이해하면 "V7에서는 믹솔리디안" 같은 규칙이 자연스럽게 이해됩니다.

5. Chordify MIDI 파일 준비 방법
================================================================================

① chordify.net 접속
② 검색창에 곡 제목 또는 YouTube URL 입력
③ 원하는 곡 클릭
④ 화면 오른쪽 하단 "EXPORT" 버튼 → "MIDI" 선택
⑤ 다운로드된 .mid 파일을 프로그램에 업로드

주의:
  · Chordify의 MIDI는 코드 트리거(온셋)만 담긴 파일입니다 (멜로디 없음).
  · BPM이 고정된 경우 더 정확합니다. 템포 변화가 많은 클래식 곡은 싱크가 어렵습니다.
  · 싱크가 안 맞으면 Sync Offset 슬라이더로 ±500ms 범위에서 보정하세요.

6. 실전 학습 가이드 (단계별)
================================================================================

【Level 1 — 지판 읽기】
  목표: 코드 구성음이 지판 어디에 있는지 눈으로 파악한다.

  1. Chord Only 모드 ON + Label 모드: 음계
  2. 영상을 재생하여 현재 코드를 확인
  3. 초록색 점들의 위치를 외운다
  4. 실제 기타에서 그 점들을 짚어본다 (소리 내지 않아도 OK)

  ★ 이 단계의 핵심: 코드가 바뀔 때마다 코드톤 위치가 어떻게 바뀌는지 관찰

【Level 2 — 펜타토닉으로 즉흥연주】
  목표: 마이너 펜타토닉 박스 1로 전 구간 즉흥연주

  1. Pentatonic 모드 ON
  2. 청록색 점들을 보면서 자유롭게 연주
  3. 논-다이아토닉 코드(황금색 Penta-Match)가 나오면 그 음을 강조해 본다
  4. Penta-Avoid(어두운 회색)는 가능하면 피한다

  ★ 이 단계의 핵심: 틀린 음을 두려워하지 말고 일단 쳐보기

【Level 3 — 코드톤 타겟팅】
  목표: 코드가 바뀔 때마다 근음(빨간점)에 착지한다.

  1. 일반 모드 (Pentatonic OFF)
  2. 코드가 바뀌는 순간 빨간 점에 1음 도달한다
  3. 그 주변의 초록점들(코드톤)을 연결한다
  4. 타임라인 탭 열고 다음 코드의 근음 위치를 미리 파악

  ★ 이 단계의 핵심: 코드 체인지에 "착지"하는 습관

【Level 4 — 논-다이아토닉 코드 공략】
  목표: 황금색 음이 나올 때 당황하지 않고 활용한다.

  1. 논-다이아토닉 코드 경고(앰버 배너)가 뜨면 집중
  2. Gray 모드 ON → 황금색과 빨간색만 집중
  3. 스케일 추천(💡) 표시를 참고해 다른 스케일 시도
  4. Pre NonD 모드로 미리 예고 음 파악

  ★ 이 단계의 핵심: "틀린 음"이 아니라 "색깔이 다른 음"으로 인식하기

【Level 5 — 어프로치 노트 활용】
  목표: 크로매틱 어프로치로 재즈/고급 느낌 추가

  1. Approach 모드 ON + Chord Only 모드 ON
  2. 인디고 점선(→) 에서 바로 옆 초록점(코드톤)으로 해머온 연습
  3. 코드 체인지 직전에 다음 코드의 근음 어프로치 노트 밟기
  4. 릭 라이브러리 탭의 "크로매틱 어프로치 노트" 릭 TAB 따라 연습

  ★ 이 단계의 핵심: 반음 위→아래 움직임의 긴장-해결 느낌 체감

【Level 6 — 모드 활용】
  목표: 스케일 추천에 나오는 모드들을 실제로 연주에 적용

  1. V7 코드가 나올 때 → 믹솔리디안 시도 (도수 모드로 ♭7 확인)
  2. ii 코드가 나올 때 → 도리안 시도 (마이너에 장6도 추가)
  3. 타임라인에서 로마 숫자 배지를 보고 코드 기능 암기

7. 기타 이론 핵심 요약
================================================================================

────────────────────────────────────────
7-1. 다이아토닉 / 논-다이아토닉이란?
────────────────────────────────────────

  다이아토닉 (Diatonic): 조성 안의 음/코드
    C Major에서: C D E F G A B → 이 7개 음만 사용 = 다이아토닉

  논-다이아토닉 (Non-Diatonic): 조성 밖의 음/코드
    C Major에서 Eb, Bb, Ab 등은 다이아토닉 세트 밖 → 논-다이아토닉

  논-다이아토닉 코드 예 (C Major에서):
    · Eb  (♭III) — 차용화음 (C Minor에서 빌려옴)
    · Bb  (♭VII) — 믹솔리디안 느낌
    · Ab  (♭VI)  — 드라마틱 전환
    · A7  (VI7)  — Am의 도미넌트, 이중 도미넌트

  논-다이아토닉 코드가 나오면 기존 스케일이 "맞지 않으며",
  해당 코드의 루트 기준으로 스케일을 전환하거나, 크로매틱으로 접근합니다.

────────────────────────────────────────
7-2. 모드(Mode) — 도리안, 믹솔리디안 등
────────────────────────────────────────

  메이저 스케일(C D E F G A B)의 시작점을 바꾸면 모드가 됩니다.

  모드명       시작음  느낌/사용 상황
  ─────────────────────────────────────────────────
  Ionian       I   C  밝고 안정적. 메이저 스케일 = Ionian
  Dorian       ii  D  마이너이지만 장6도가 밝은 느낌. (ii, iv 코드)
                       예: Santana, 재즈 마이너
  Phrygian     iii E  스페인/플라멩코 느낌. 반음 위 ♭2도가 특징
  Lydian       IV  F  몽환적, 밝은 느낌. ♯4도가 특징. (영화음악)
  Mixolydian   V   G  블루스/록 느낌. ♭7도가 특징. (V, V7 코드)
                       예: 록 리프, 블루스, 펑크
  Aeolian      vi  A  내추럴 마이너 = Aeolian. (vi, i 코드)
  Locrian      vii B  불안정, 긴장. (vii°, 잘 사용 안 함)

  ★ 실용 요약:
    · 마이너 코드 위 → 도리안 또는 에올리안 시도
    · 도미넌트 7코드(V7) 위 → 믹솔리디안 시도
    · 메이저 코드(IV) 위 → 리디안 시도

────────────────────────────────────────
7-3. 펜타토닉 스케일
────────────────────────────────────────

  블루스, 록, 팝에서 가장 많이 쓰이는 5음 스케일.

  Minor Pentatonic: 1 ♭3 4 5 ♭7
  Major Pentatonic: 1 2  3 5 6

  박스 포지션 (Am Minor Pentatonic, 5번 프렛 기준):
    e|--5--8--|
    B|--5--8--|
    G|--5--7--|
    D|--5--7--|
    A|--5--7--|
    E|--5--8--|

  이 박스를 루트만 바꾸면 어느 조성에서도 사용 가능합니다.

────────────────────────────────────────
7-4. 크로매틱 어프로치 노트
────────────────────────────────────────

  코드톤의 반음 아래(또는 위)에서 코드톤으로 이동하는 기법.

  종류:
    Lower Chromatic Approach: 코드톤 반음 아래에서 위로 → (가장 일반적)
    Upper Chromatic Approach: 코드톤 반음 위에서 아래로 ↓
    Double Chromatic:         반음 아래→코드톤 또는 반음 위→코드톤 두 방향

  예 (Am7 코드, 근음 A 어프로치):
    │--4h5--│  (G#→A, 해머온)  ← Lower Chromatic

  이 프로그램에서: [Approach] 모드 ON → 지판의 → 점(인디고)이 어프로치 노트 위치

────────────────────────────────────────
7-5. 코드 기능 (Roman Numeral Analysis)
────────────────────────────────────────

  코드를 조성 안에서의 역할로 분류하면 패턴이 보입니다.

  자주 나오는 진행 패턴:
    ii → V → I     (재즈의 기본, 강한 해결감)
    I → IV → V     (블루스, 팝의 기본)
    I → vi → IV → V (50년대 팝, 수많은 팝송)
    i → ♭VII → ♭VI → V  (마이너 클래식 진행)

  로마 숫자 읽는 법:
    대문자 (I, IV, V)  = 메이저 코드
    소문자 (ii, iii, vi) = 마이너 코드
    °           = 디미니시드
    7 추가       = 7th 코드 (예: V7 = 도미넌트 세븐)
    Δ 추가       = 메이저 7th (예: IΔ7)
    ♭ 앞에 붙으면 = 반음 내려간 (예: ♭VII = 장7도 아래)

8. 자주 묻는 질문 (FAQ)
================================================================================

Q. 영상과 MIDI가 안 맞아요.
A. Sync Offset 슬라이더를 조정하세요. 코드가 실제보다 늦게 바뀌면 +방향,
   너무 일찍 바뀌면 -방향으로 조정합니다. ±500ms 범위에서 보정 가능합니다.

Q. 조성 자동 감지가 틀렸어요.
A. Master Key 드롭다운에서 직접 루트와 Major/Minor를 선택하세요.
   Chordify의 MIDI는 때때로 여러 조성이 혼재하여 감지가 어렵습니다.

Q. YouTube 영상이 안 불러와져요.
A. 유튜브 URL 전체나 영상 ID (11자리 영문/숫자)를 입력해보세요.
   일부 영상은 임베드가 차단되어 있습니다. 그런 경우 로컬 파일 탭을 이용하세요.

Q. 로컬 영상이랑 MIDI를 쓰는데 싱크가 안 맞아요.
A. 로컬 영상은 파일을 불러온 후 재생 버튼을 눌러야 싱크가 시작됩니다.
   Sync Offset으로 미세 조정하세요.

Q. 릭 라이브러리의 TAB 프렛 번호가 제 조성이랑 맞지 않는 것 같아요.
A. 릭은 Am 기준으로 정의되고, 현재 코드 루트로 자동 조옮김됩니다.
   카드 하단의 "기준 포지션: X — 로우 E X프렛 근처"를 참고하세요.
   프렛이 12 이상이면 포지션이 높아진 것으로, 동일 음은 12칸 차이 위/아래에도 있습니다.

Q. Approach 모드를 켜도 점이 너무 많이 떠서 보기 힘들어요.
A. Chord Only 모드와 함께 사용하면 코드톤과 어프로치 노트만 표시되어 훨씬 깔끔합니다.
   또는 Gray 모드와 함께 쓰면 논-다이아토닉 음에만 집중할 수 있습니다.

Q. 최근 기록이 5개밖에 안 돼요.
A. 최대 5개가 저장됩니다. 오래된 항목은 자동 삭제됩니다.
   운지 선호도는 별도로 최근 20곡까지 저장됩니다.

Q. 모바일에서 사용할 수 있나요?
A. 기본 동작은 가능하지만, 21프렛 지판이 가로로 넓어서 스크롤이 필요합니다.
   태블릿 가로 모드를 권장합니다.
